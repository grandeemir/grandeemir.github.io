# Cybersecurity Portfolio

A lightweight, static portfolio website with a cybersecurity theme.

## Features

- 🎨 Dark theme with terminal aesthetics
- 📱 Fully responsive design
- ⚡ Lightweight and fast (no frameworks)
- 🔒 Cybersecurity-themed UI elements
- ✨ Animated typing effect

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
